03 /The next chapter

PRE-V1 · IN DEVELOPMENT

One program.
Your entire node.
Meet Z23.

An independent Zclassic full node, written in C23. Download the chain from peers and verify every block yourself — including the proofs behind shielded payments.

Explore Z23 on GitHub
build-your-own.sh
$ git clone https://github.com/z23c/z23.git
$ cd z23
$ make doctor
$ make setup && make -j z23
$ build/bin/z23
Native C23No Rust toolchainBuild from source

Linux requires GCC 14+ or a C23-capable Clang, GNU Make, and a C++ compiler. Read the setup guide ↗

Verify locally.

Native shielded proof verification. No proving parameters needed to sync.

Tor, built in.

On by default, with your own .onion address. No DNS seeders.

Your own explorer.

A block explorer and JSON API served directly by your node.

Wallet + RPC.

Transparent and shielded wallet state, with an interface for your tools.

Built to recover.

Designed to survive hard stops and explain what holds up progress.
